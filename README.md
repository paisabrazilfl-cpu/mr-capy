# Mr. Capy

A Mario-style platformer game starring Mr. Capybara.

## Setup
1. Clone the repo:
   ```bash
   git clone https://github.com/paisabrazilfl-cpu/mr-capy.git
   cd mr-capy
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the game:
   ```bash
   npm run dev
   ```

## Controls
- **Arrow keys**: Move
- **Space**: Jump

## Assets
Place these in `public/assets/`:
- `sky.png` (background)
- `platform.png` (ground tiles)
- `capy.png` (32x48px spritesheet: frames 0-3 = run left, 4 = idle, 5-8 = run right)
